# Uztronix Holding — Telegram Mini App

Личный кабинет сотрудника холдинга Uztronix.

## Возможности

- KYC до ввода телефона; кабинет открывается только после одобрения документов
- Вход по номеру телефона из белого списка после подготовки KYC
- Личный кабинет: аванс, должность, отдел, стаж
- Вывод средств на карту (только разрешённые номера карт)
- Управление данными через Telegram-бота

## Запуск

```bash
cp .env.example .env
npm install
npm run build
npm start
```

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `BOT_TOKEN` | Токен Telegram-бота |
| `EXPECTED_BOT_USERNAME` | Username ожидаемого бота без `@`; запуск блокируется, если токен принадлежит другому боту |
| `ADMIN_IDS` | ID администраторов через запятую |
| `WEBAPP_URL` | URL Mini App для кнопки в боте |
| `DATA_DIR` | Путь к Volume на Railway (по умолчанию `/main` если смонтирован, иначе `./data`) |
| `BROWSER_ADMIN_PATH` | Секретный путь браузерной админ-панели (по умолчанию `/ops-uztronix-x7m2`) |
| `BROWSER_SESSION_SECRET` | Секрет подписи cookie браузерного входа (иначе используется `BOT_TOKEN`) |
| `GOOGLE_SHEETS_ID` | ID Google-таблицы для real-time синхронизации |
| `GOOGLE_SHEETS_TAB` | Имя вкладки (по умолчанию `Сотрудники`) |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | JSON ключ service account (одной строкой) |
| `PORT` | Порт сервера (по умолчанию 3000) |

### Railway Volume

Смонтируйте Volume в `/main` — телефоны, сессии и профили сотрудников сохраняются между деплоями.
В логах при старте: `Data directory: /main`.

### Google Sheets (real-time)

1. Создайте Google Spreadsheet, вкладку назовите `Сотрудники`
2. Создайте Service Account в Google Cloud, включите Sheets API
3. Дайте service account email доступ «Редактор» к таблице
4. В Railway добавьте `GOOGLE_SHEETS_ID` и `GOOGLE_SERVICE_ACCOUNT_JSON` (весь JSON одной строкой)

Таблица обновляется автоматически при любом изменении данных. Также: `/export` в боте — Excel-файл.

## Команды бота (дополнительно)

**Операторы:** `/addoperator TelegramID Имя` `/linkoperator` `/listoperators`  
`/pickoperator +998...` — выбор кнопкой или своё имя  

**Служебный веб-интерфейс:** оператор или администратор открывает Mini App через кнопку меню Telegram и вводит номер `742951`. Сервер дополнительно проверяет Telegram ID по сохранённым спискам ролей. Веб-сессия действует 12 часов.

**Браузерная админ-панель:** администраторы могут открыть секретный путь (по умолчанию `https://<host>/ops-uztronix-x7m2`), войти по своему Telegram ID и номеру `742951`. Это тот же интерфейс, но в обычном браузере с большим окном. Путь можно сменить через `BROWSER_ADMIN_PATH`. На этот же URL можно повесить отдельный домен в Railway.

**Telegram-панель:** `/admin`, `/panel` или `/operator` — только для сохранённых Telegram ID, без дополнительного номера. Команда `/start` отправляет кнопку открытия Mini App.

**ID клиента:** автоматически `1`, `2`, `3`… Поиск по ID или телефону.

📖 **Инструкция для операторов:** [docs/OPERATOR_GUIDE.md](docs/OPERATOR_GUIDE.md)

**Кто внёс — тот и ведёт клиента.** Управление — кнопками в защищённом служебном меню.

**Теги:** при добавлении — текст, фото или оба в одном шаге (или «Без вложений»).  
**Данные клиента** (имя, должность, отдел, стаж, аванс) — кнопка «✏️ Данные» в карточке.  
**Сводки:** «Сегодня» (имя, телефон, оператор), «Сводка оп.» (клиенты и теги по операторам).  
**Рассылка:** одному / всем своим / всем (с подтверждением всех операторов или одного админа).  
**Операторы и админы** — добавляются кнопками в панели.

**Админы:** `/addadmin 123456789` `/removeadmin 123456789` `/listadmins`  
**Экспорт (только админ):** `/export`

## Команды бота

**Телефоны (доступ в систему):**
- `/add +998901234567` — разрешить вход
- `/remove +998901234567` — удалить
- `/list` — список телефонов

**Профиль сотрудника:**
- `/set +998901234567 name Alisher Karimov`
- `/set +998901234567 position Bosh muhandis`
- `/set +998901234567 dept Telekommunikatsiya`
- `/set +998901234567 tenure 3 yil 6 oy`
- `/set +998901234567 balance 2500000`
- `/set +998901234567 id UZT-042`
- `/set +998901234567 operator Имя` / `/set +998901234567 tag v_rabote` (добавить тег)
- `/employee +998901234567` — просмотр профиля
- `/employees` — список всех

**Карты (вывод средств):**
- `/addcard +998901234567 8600123456789012`
- `/removecard +998901234567 8600123456789012`
