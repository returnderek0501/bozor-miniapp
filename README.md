# Uztronix Holding — Telegram Mini App

Демо-версия официального портала холдинга Uztronix (Узбекистан).

## Возможности

- Вход только по номерам телефона из белого списка
- Администратор управляет списком через Telegram-бота (команды и кнопки)
- При неавторизованном номере — сообщение о неподдерживаемых старых SIM-картах
- Официальный стиль интерфейса (узбекский / русский)

## Запуск локально

```bash
cp .env.example .env
# Укажите BOT_TOKEN и ADMIN_IDS
npm install
npm run dev        # фронтенд :5173 (прокси /api → :3000)
# В отдельном терминале:
PORT=3000 node server.js
```

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `BOT_TOKEN` | Токен Telegram-бота |
| `ADMIN_IDS` | ID администраторов через запятую |
| `WEBAPP_URL` | URL Mini App для кнопки в боте |
| `PORT` | Порт сервера (по умолчанию 3000) |

## Команды бота (админ)

- `/start` — приветствие и кнопка Mini App
- `/admin` — панель управления с кнопками
- `/add +998901234567` — добавить номер
- `/remove +998901234567` — удалить номер
- `/list` — список разрешённых номеров
